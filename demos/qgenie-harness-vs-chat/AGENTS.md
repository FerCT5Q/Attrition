# Demo project instructions

This folder is a self-contained demonstration for the QGenie Chat versus
harness presentation. Treat the project as a small project-coordination job.

## Working rules

- Write all narrative output in Spanish.
- Treat files under `input/` as read-only source material.
- Use `input/project_status.csv` as the quantitative source.
- Use `input/meeting_notes.md` for qualitative context only.
- Use `input/project_rules.md` as the governing business rules.
- Do not invent dates, owners, causes, or status values.
- If two sources disagree, report the disagreement instead of resolving it
  silently.
- Create or update files only under `output/`.
- Before writing, present a short plan and wait for approval when the user asks
  for a plan-first workflow.

## Expected deliverables

The approved workflow should produce:

- An executive status report.
- A validation and source-notes file.
- An action tracker with owners expressed as teams, not individuals.
