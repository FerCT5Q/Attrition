# Checklist de calidad

Recórrelo antes de entregar cualquier visualización. Un punto que no aplica se
omite; uno que falla se corrige o se reporta como limitación.

## Mensaje

- [ ] La conclusión se puede decir en una frase.
- [ ] El mensaje precisa quién, qué, comparado con qué o en qué periodo.
- [ ] La redacción corresponde a la evidencia y evita causalidad no
      demostrada, también en títulos, anotaciones y notas.
- [ ] Se reconocen las limitaciones y los datos faltantes relevantes.

## Elección del gráfico

- [ ] El tipo de gráfico corresponde al mensaje.
- [ ] Cada gráfico comunica un mensaje.
- [ ] Intervalos de tiempo, datos faltantes y orden de categorías se
      representan con honestidad.
- [ ] Se consideró si una cifra, tabla o diagrama era mejor que un gráfico.

## Diseño

- [ ] Cada elemento visible cumple una función.
- [ ] Se retiraron los elementos por defecto innecesarios.
- [ ] Los valores clave están etiquetados sin generar ruido.
- [ ] El color crea un foco claro.
- [ ] Se lee con deficiencias de visión de color (etiquetas, marcadores o
      estilos además del color).
- [ ] Los ejes de barras empiezan en cero.
- [ ] El rango de las líneas es informativo sin exagerar.
- [ ] El texto se lee al tamaño y en la pantalla de destino.

## Interpretación

- [ ] El título expresa la conclusión con lenguaje activo.
- [ ] El benchmark o rango de referencia más útil está incluido y rotulado.
- [ ] Las anotaciones responden preguntas probables sin exagerar certeza.
- [ ] El gráfico se entiende si se reenvía sin su contexto original:
      población, ventana, unidad, n y fuente están visibles.

## Revisión

- [ ] Los números se verificaron contra la fuente; totales y denominadores
      cuadran.
- [ ] Se consideraron alternativas cuando la elección era ambigua.
- [ ] Se intentó refutar el mensaje en lugar de sólo confirmarlo.
- [ ] Se revisaron los trade-offs antes de aceptar cambios.
- [ ] Se aplicaron las [extensiones de Attrition](extensiones-attrition.md)
      cuando el gráfico usa datos de RH.
