# Criterios de inclusión y exclusión

## Inclusión

Se incluye un trabajo si cumple al menos una condición:

- estudia employee turnover, attrition, withdrawal o retention;
- aporta un método para datos longitudinales de empleados;
- resuelve censura, riesgo temporal, competing risks o intervención;
- aporta evidencia sobre engagement, manager, carrera, movilidad, equipos,
  compensación o technical talent;
- analiza fairness, privacidad o gobierno de modelos de empleo.

## Exclusión

- contenido comercial sin método ni datos verificables;
- duplicados o versiones inferiores del mismo trabajo;
- modelos sin información suficiente de población, target o validación;
- scraping o identity matching no aprobado como recomendación operativa;
- estudios transversales que no aporten una lección transferible.

## Etiquetas

- `fundacional`: método estadístico base;
- `aplicado-turnover`: evidencia directa de salidas de empleados;
- `people-analytics`: variables y decisiones de RH;
- `challenger`: algoritmo alternativo;
- `accionabilidad`: intervención, causalidad o uplift;
- `gobierno`: fairness, privacidad o uso responsable;
- `futuro`: texto o método avanzado fuera del MVP.
