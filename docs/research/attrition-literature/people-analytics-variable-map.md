# Mapa de variables de People Analytics

| Constructo | Variables del proyecto | Papel | Acción posible |
|---|---|---|---|
| Trayectoria | Company tenure, time in role, promotion | Control y señal | Carrera/movilidad |
| Rol técnico | Critical Tech family, seg, level | Scope y contexto | Workforce/career paths |
| Manager | Manager change, manager leaving, number of changes | Señal contextual | Manager enablement |
| Equipo | Team turnover, high turnover under person | Señal agregada | Staffing/diagnóstico |
| Movilidad | Transfer, applied to a job | Señal potencial | Movilidad interna |
| Engagement | QVoice engagement, intent to stay, career goals | Señal accionable | Listening/action plan |
| Compensación | Compa-ratio y bandas relativas | Señal gobernada | Review agregado |
| Trabajo | Work arrangement, co-location | Contexto/palanca | Diseño del trabajo |
| Mercado | Labor market y desempleo externo | Contexto | Retention/recruiting strategy |
| Fairness | Gender y otros protegidos | Auditoría | No usar para targeting |
| Texto | Comentarios QVoice o LinkedIn | Línea futura | Sólo con gobernanza |

La disponibilidad técnica no implica que una variable sea una palanca. Cada
variable debe tener fecha de conocimiento, grain, cobertura, limitaciones y
acción posible antes de entrar al modelo o a un reporte.
